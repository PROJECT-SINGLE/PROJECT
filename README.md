TheColor — Guia de Execução do Projeto
📌 Sobre o projeto
O TheColor é uma aplicação que trabalha com gerenciamento de usuários, quizzes e uma biblioteca de cores, integrando frontend, backend e banco de dados.

Como rodar o projeto
Siga o passo a passo abaixo para executar o sistema corretamente.
1. Clonar o repositório
git clone da pasta "TheColor"

Depois entre na pasta:
cd TheColor
2. Instalar o Node.js

Antes de tudo, verifique se você tem o Node.js instalado.
Caso não tenha, instale pelo site oficial:
https://nodejs.org/

3. Instalar dependências
Dentro da pasta do projeto, execute:

npm i
Esse comando irá instalar todas as bibliotecas necessárias.

4. Iniciar o projeto
Após a instalação das dependências, rode o projeto com:

npm start

5. Configuração do banco de dados
Antes de usar o sistema, é necessário configurar o banco de dados.
Passo a passo:
Abrir o MySQL Workbench
Executar o script do banco de dados do projeto
Criar as tabelas e inserir os dados iniciais
Garantir que o banco esteja rodando corretamente

⚠️ Importante
O banco de dados deve estar ativo antes de iniciar o projeto
O Node.js é obrigatório para rodar o frontend/backend
Execute os comandos sempre dentro da pasta do projeto
OBS.: ALGUNS ARQUIVOS E PASTAS FORAM DISPONIBILIZADOS PELA INSTITUIÇÃO SPTECH COM ISSO, HA ARQUIVOS E MATERIAIS DO MATERIAL DISPONIBILIZAO. 

Resumo
Para rodar o TheColor, basta:
Clonar o repositório
Instalar o Node.js

Rodar npm start
